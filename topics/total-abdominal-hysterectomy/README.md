# ✂️ Total Abdominal Hysterectomy (TAH) Operative Manual

Part of the **[MedEd Open Platform](../../README.md)**.

## 📌 Overview

This topic provides an evidence-based, step-by-step surgical manual and resident quick-reference guide for **Total Abdominal Hysterectomy (TAH)**. It emphasizes retroperitoneal ureter identification, clamp placement following the *"Roundness of the Cervix"*, Center-to-Lateral bladder mobilization, hemostasis pearls, and Enhanced Recovery After Surgery (ERAS) protocols.
